# 遇到问题

[README](../README.md) 是产品介绍和安装指南，这份专门收集「出了岔子怎么办」。

## 装的时候双击没反应

Windows 可能会拦一下，弹出一个蓝色的框说「**Windows 已保护你的电脑**」。

这是正常的。点框里的 **「更多信息」**，再点下面出现的 **「仍要运行」** 就行，只需要放行这一次。

原因：这个软件没有买代码签名证书。所有没买证书的免费软件下载后都会遇到这个提示，不是它有问题。

## 点她没反应

她的窗口四周留了一圈**看不见的透明边距**（给呼吸和弹跳留的空间）。那圈透明的地方是**点不中的** ——
鼠标会穿透过去，落到她后面的窗口上。

所以要点就点在角色身上，别点她周围的空白。

第一次运行的时候，她会自己弹一句提示告诉你这件事。

## 点她的时候余额显示「未设置 API Key」

不是故障，是你还没填 Key。填法看 [README 的「让她报余额」](../README.md#让她报余额可选)。
不填也能用，只是她报不出余额。
