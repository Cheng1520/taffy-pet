# 塔菲桌宠

一只 Q 版塔菲住在你的 Windows 桌面上。点她一下，她会跟你说话，顺便告诉你 DeepSeek 账户里还剩多少钱。双击她，还能跟她聊起来。

她平时会自己慢慢呼吸、偶尔眨眼睛，脚下有一小片影子，还会**一直看着你的鼠标**。
没人理她的时候，过一会儿她会自己找点事做 —— 说句话、蹦一下，或者跳个舞。
不吵不闹，就在屏幕右下角待着。

## 装

1. 到 [Releases](https://github.com/Cheng1520/taffy-pet/releases) 页面，下载 `TaffyPet-Setup-1.0.0.exe`
2. 双击它，一路点「下一步」
3. 装完她就在你屏幕右下角了

安装**不需要管理员权限**，也不会弹 UAC 窗口。

## 用

| 你想干什么 | 怎么做 |
| --- | --- |
| 让她说话 / 看余额 | **左键点她一下** |
| 和她说话 | **双击她**，或右键 →「和她说话」 |
| 让她跳个舞 | 右键 →「跳个舞」，**或者干脆别理她**（见下） |
| 挪个位置 | **按住左键拖**，松手就记住了，下次打开还在那 |
| 改设置 / 关掉她 | **右键点她** |

**想关掉她**：右键点她 →「退出」。

**没空理她也行**：她会自己动，不用你点任何东西。见「[她自己会动](#她自己会动)」。

## 她会出声

点她的时候她会**喵一声**。默认开着，右键 →「说话出声」可以关掉。

**她不是把回复念出来**，这一点值得说清楚：真正做这件事（一句话念出来）在这种机器上
要等一两分钟，没法用在桌宠上。所以做的是**事先剪好一批台词，回复进来时按关键词挑一句
最贴的播**：

- 你说到「游戏」→ 她说「打游戏最重要的就是开心呀」
- 你说到「吃饭」「好吃」→ 她说「好吃的喵」
- 你说到「再见」「下线」→ 她说「拜拜喵」
- 挑不到合适的就**不出声** —— 随便播一句不相关的话，听起来比安静更像坏了

换句话说，**她出不出声和聊天的内容只是大致相关**，别当成她在逐字念回复。

**台词是她的原声，不是合成的。** 库里这 12 段是从她的公开视频里按**词级时间戳**
剪出来的真人片段，一句一文件。早先试过用 F5-TTS 克隆，拿说话人验证一量，
每个克隆输出都低于她自己录音的下限 —— 听着也确实不像（原话是「雷霆声音」），
所以整条路放弃了。

代价是**句子少**。直播录播剪不出能当台词的句子（那是情境对话，剪出来全是
「汪小母狗小母狗」这类），只能从粉丝整理的语音包和「怪话怪叫」合集里捡；
同时满足「一句完整的话、像她、时长合适」的就这 12 句。宁缺毋滥 ——
与其塞 20 句不像的，不如这 12 句句句是她。

## 她自己会动

桌宠最别扭的一点是：**没人会对着一个小人右键**。跳舞、说话这些动作全塞进右键菜单，
等于没做 —— 用户根本不知道有这些东西。

所以她**没人理的时候会自己找事做**。你 45～110 秒不碰她，她会随机挑一件：

| 她自己做的 | 多久出现一次 |
| --- | --- |
| 说一句话（真的出声，头顶也会浮出那句话） | 最多，一半左右 |
| 蹦一下 | 其次 |
| 跳个舞 | 最少 —— 这个最抢戏，老跳会烦 |

三件事的间隔是**随机的**，不是固定周期：固定周期过两天就成了节拍器，比不动还假。
你一碰她（点、拖、开聊天窗）计时就从头算，因为「她自己找事做」的前提是**你确实没在理她**。

不想让她自己动：右键 →「自己找事做」，关掉。这个开关会记住。

## 她会跳舞

跳舞用的是素材里那段 0.85 秒的独舞，**正着放一遍再倒着放一遍**接成循环，
所以首尾接得上、不会一跳一顿。

有两种法子看到：

- **让她自己跳** —— 见上面那节，你什么都不用做
- **右键 →「跳个舞」** —— 想立刻看的时候就点这个

跳三遍，跳完自己回到待机。跳舞期间点她不会打断，重复点会重头跳。

## 她会看着你

她脚下的影子会跟着弹跳一起缩小、变淡 —— 那是整幅画面里**唯一**说明「她离地多高」
的线索，没有它的话弹跳看着就是一张图在缩放。

她还会朝鼠标那一边微微歪一点。这个幅度刻意压得很小（3.2 度）：她只有一张平面立绘，
没有骨骼，整张图一起转幅度一大脸就跟着歪，看着是「图片在转」而不是「她在转头」。

## 让她报余额（可选）

**不做这一步她也能用**，只是你点她的时候，余额那一行会显示「未设置 API Key」。

想让她报余额的话，需要一个 DeepSeek 的 API Key：

1. 右键点她 →「设置 API Key」
2. 把 `sk-` 开头的那串 Key 粘进去，点确定

Key 只存在你自己电脑上的 `%APPDATA%\TaffyPet\config.json`，除了发给 DeepSeek 本身，
不会发到别的地方去。

## 和她说话

用的就是上面那个 Key —— 也就是 **DeepSeek 自己的 API Key**。她聊天和查余额走的都是
DeepSeek 自己的服务，所以**别的厂家给的 Key 填进去用不了**。

没设置 Key 的话，她只会回一句「还没设置 API Key」，右键点她 →「设置 API Key」填上就行。

**怎么开**：双击她，或者右键点她 →「和她说话」。窗口里**回车发送**，`Shift + 回车` 换行。
她的话是一个字一个字蹦出来的；这期间发送按钮会变成「停止」，点一下就能打断她。

**她不是只会聊天。** 给她装了三个小能力：知道现在几点、记得住你说过的事、以及
跟你正常闲聊。她说要去查时间的时候，气泡下面会多出一行小字，写着她实际查到的东西
（比如「现在是 2026 年 9 月 15 日 03:12（凌晨，星期二）」）—— 那是**旁白，不是她说的话**，
所以它比气泡小一号、颜色也更淡。她记东西也走这条路，说一句「记住我爱熬夜」就能看见。

第一次打开、还一句都没聊过的时候，输入框下面会有三个可以点的短句。点一下就当你说过了，
不用自己想着该说什么。（聊过之后它们就收起来，不再占地方。）

**这一步是要花钱的**：你每说一句，她都要去问一次 DeepSeek，而且每次都会把最近 20 条
对话一起发过去（不然她记不住你上一句说了啥），所以比点一下查余额贵得多。余额还是点她
一下看。

**你发的话和她的回复都会发到 DeepSeek 的服务器去**，聊天记录是明文存在你自己电脑上的
`%APPDATA%\TaffyPet\chat.json`。不想留了就右键点她 →「清空对话记录」（会先问你一次），
清完她会当没聊过，重新跟你打招呼。

想自己动手删那个文件也行，但**得先右键点她 →「退出」**：她开着的时候整份记录都在内存里，
下一句话就会把它整份写回去 —— 删了等于没删。（跟改 `config.json` 一个道理，那份也说了
「改之前先退出」。）

## 调整她

她的大小、透明度、说的话，都可以改。

设置文件在 `%APPDATA%\TaffyPet\config.json`。想打开它：按 `Win + R`，粘下面这行，回车。

```
%APPDATA%\TaffyPet
```

改之前先右键点她 →「退出」，改完再打开她。

常用的几项：

| 想改什么 | 改哪个 | 默认值 |
| --- | --- | --- |
| 她多大 | `height` | `200` |
| 透明度 | `opacity` | `1.0` |
| 音量 | `volume` | `1.0` |
| 她说什么 | `speech` | `关注塔菲喵关注塔菲谢谢喵` |
| 要不要眨眼 | `blink` | `true` |
| 要不要出声 | `voice` | `true` |
| 要不要让她自己用工具 | `agent` | `true` |
| 要不要让她自己找事做 | `idle` | `true` |
| 要不要总在最前 | `always_on_top` | `true` |
| 她的人设（怎么说话） | 右键 →「编辑人设」 | 见 `persona.md` |

**她的人设**是单独一个文件：点「编辑人设」，她会用系统默认的程序（一般是记事本）把文件
打开，改完存盘，你下一句话就按新的来，不用重启。文件在 `%APPDATA%\TaffyPet\persona.md`，
是你自己的一份，升级程序不会覆盖。

`height` 是「逻辑像素」，会跟着你系统的缩放比例走。觉得小了就改大，比如 `300`。

**把整个 `config.json` 删掉，就全部恢复默认。**

## 卸载

Windows「设置 → 应用 → 已安装的应用」里找到「塔菲桌宠」，点卸载。

卸载**不会**删掉你的 API Key，聊天记录也一样留着 —— 万一以后想再装回来，不用重新填一遍、也还能接着聊。想彻底清干净，把 `%APPDATA%\TaffyPet` 这个文件夹也删掉。

**语音库和跳舞素材是安装包装进去的**，所以卸载时会被一起带走（它们在
`%APPDATA%\TaffyPet\voice\` 和 `dance\`，装完就能出声、就能跳舞，不用另配）。
卸载器只删自己装进去的那几个文件，`config.json`、`chat.json`、`memory.md`
是你自己攒出来的东西，一个都不碰。
