# 塔菲桌宠

把 Q 版立绘抠出来放在 Windows 桌面上。点一下她会说话、报一次 DeepSeek 账户余额，
平时自己慢慢呼吸、偶尔眨眼睛。

只有一张立绘，呼吸／弹跳／眨眼全靠程序化变换做出来，不需要任何序列帧素材。

## 功能

- **点击说话** —— 点她一下，说「关注塔菲喵关注塔菲谢谢喵」（可配置），同时播音效、蹦一下
- **显示 DeepSeek 余额** —— 点击时一并查询，和台词显示在同一个气泡里
- **程序化动画** —— 呼吸、眨眼、点击弹跳，全部由一张立绘变换而来
- **拖动换位置** —— 松手后记住，下次启动还在原地
- **右键菜单** —— 设置 API Key / 刷新余额 / 眨眼开关 / 窗口置顶 / 退出
- **无边框透明置顶窗口** —— 不占任务栏，透明的地方点得穿，不会挡住下面的桌面图标
- **双击图标启动，不会起出第二只**（连点两下只会让她蹦一下）

## 环境要求

| | |
| --- | --- |
| 系统 | Windows 10 / 11（用了透明分层窗口、`pythonw.exe`、命名管道） |
| Python | 3.8 或更新（开发时用的是 3.13） |
| 依赖 | `pip install -r requirements.txt` |

跑桌宠本身只需要 **PyQt5** 和 **requests**；requirements 里的 Pillow／numpy／scipy／
opencv-python 只有重新生成素材（`tools/`）时才用得到。

## 快速开始

```bash
pip install -r requirements.txt
python main.py
```

她默认出现在**屏幕右下角、任务栏上方**，大约占屏幕高度的四分之一。首次运行会弹一次提示
气泡，说明可以拖、可以右键。

### 想双击启动的话

```bash
python tools/make_shortcut.py
```

它会生成 `assets/taffy.ico`（拿她的头做的）并在桌面创建「塔菲」快捷方式，以后双击就能启动。
一台机器跑一次就够，不需要重新生成素材。

快捷方式指向 `pythonw.exe` 而不是 `python.exe` —— 后者会在桌面上挂一个黑框命令行窗口，
而关掉那个窗口会把桌宠一起带走。

## 使用

| 动作 | 效果 |
| --- | --- |
| 左键点击 | 说话 + 弹余额 + 播音效 + 蹦一下 |
| 左键拖动 | 挪位置（松手后记住，下次启动还在那） |
| 右键点她 | 菜单：设置 API Key / 刷新余额 / 眨眼 / 窗口置顶 / 退出 |
| 退出 | 右键菜单里的「退出」—— 会把当前位置记回 `config.json` |

**右键要点在她身上。** 窗口是无边框透明的，四周留了一圈看不见的透明边距（为什么要留见
[实现笔记](docs/implementation-notes.md#窗口边距是个权衡)）。那圈透明区域**点不中** ——
透明像素会穿透到下面的窗口去，所以首次运行会自动弹一次操作提示，不然没人知道该往哪点。

拖拽和点击按位移量区分（超过 6px 算拖拽），所以想挪位置不会误触发说话。

### 看不到她 / 起不来

- 默认位置在**屏幕右下角、任务栏上方**。
- 起不来会弹一个「塔菲起不来」的框，堆栈写进项目根目录的 `taffy.log` —— 用桌面图标启动时
  没有控制台，不这么做就只会是「双击没反应」。
- 想直接看日志：在项目目录跑 `python main.py`，日志打在控制台里。

### 双击两次不会起出两只

第二个进程发现已经有一只在跑了，会让那只蹦一下、弹个「我在这儿呢～」，然后自己退出。
判断方式是占一个同名的 `QLocalServer`（`main.py` 里的 `SERVER_NAME`）—— 进程崩了名字会
自动释放，比锁文件干净。

## 配置

### API Key

两种方式，**环境变量优先**：

1. 环境变量 `DEEPSEEK_API_KEY` —— 推荐，Key 不落盘
2. 右键她 →「设置 API Key」，粘进输入框，存到 `config.json`

`config.json` 已经在 `.gitignore` 里，不会被提交。

余额走 `GET https://api.deepseek.com/user/balance`。Key 无效会显示「API Key 无效」，
网络不通显示「查询超时」，都不会影响她说话和蹦跳。

### 全部配置项

`config.json` 不存在时全部用默认值，删掉它就恢复默认。

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `height` | `200` | 角色在屏幕上的高度，单位是**逻辑像素**（跟着系统缩放比例走）。200% 缩放时 200 逻辑像素 ≈ 400 物理像素 ≈ 四分之一屏高 |
| `opacity` | `1.0` | 整体透明度，0.0 ~ 1.0 |
| `volume` | `1.0` | 音效音量 |
| `blink` | `true` | 要不要眨眼 |
| `always_on_top` | `true` | 是否总在最前 |
| `speech` | `关注塔菲喵关注塔菲谢谢喵` | 点击时说的话 |
| `api_key` | `""` | 也可以写在这里，但环境变量优先 |
| `pos` | `null` | 上次退出时的位置 `[x, y]`，程序自己写 |
| `hint_shown` | `false` | 首次运行提示过操作方式没有，程序自己写 |

## 重新生成素材

素材已经生成好了，正常跑桌宠不需要这一步。

改了原图才需要（**原图不在仓库里**，是白底单张立绘，所以要自己传路径）：

```bash
python tools/build_assets.py <原图路径>
```

产出 `assets/taffy.png`（抠图）、`assets/taffy_blink.png`（闭眼帧）、`assets/eyes.json`
（眼睛坐标），以及目检图 `assets/_blink_check.png`。

音效来自一段录屏视频，重新提取：

```bash
python tools/extract_audio.py <视频路径> click
```

脚本会掐掉首尾静音、做峰值归一化，输出 `assets/sounds/click.wav`。依赖里的
`imageio-ffmpeg` 自带一份 ffmpeg，不用另外装。

## 自检

```bash
python tools/test_units.py     # 余额解析、API Key 优先级、弹跳曲线
python tools/smoke.py          # 起窗口、截图、验证边界与幅度、检查菜单
```

冒烟测试会截几张 `assets/_smoke*.png` 然后自动退出 —— 不用盯着屏幕也能看出渲染和变换
对不对（半透明分层窗口在整屏截图里不一定抓得准，窗口自己的 `grab()` 才作数）。

## 实现笔记

几个不那么显然的地方，全文在 [`docs/implementation-notes.md`](docs/implementation-notes.md)：

- **抠图判据用彩度 `max-min`，不是「到白色的距离」** —— 浅粉头发和 JPEG 灰噪声在距离上
  数值重叠，在彩度上分得很开。
- **闭眼帧只在同一行内横向插值，永远不往上取色** —— 眼睛上方就是深色刘海，`cv2.inpaint`
  会把发色带下来，在眼睛上方抹出一块灰。
- **弹跳用关键帧，不用弹簧** —— 阻尼会把回弹那一侧吃掉，压扁 5% 而拉伸只剩 1%。
- **素材像素和显示尺寸彻底解耦** —— 高 DPI 屏上把素材 1:1 画出去，角色会整只跑到屏幕外；
  同理动画里不能有写死的像素。
