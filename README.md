# 塔菲桌宠

一只 Q 版塔菲住在你的 Windows 桌面上。点她一下，她会跟你说话，顺便告诉你 DeepSeek 账户里还剩多少钱。

她平时会自己慢慢呼吸、偶尔眨眼睛，不吵不闹，就在屏幕右下角待着。

## 装

1. 到 [Releases](https://github.com/Cheng1520/taffy-pet/releases) 页面，下载 `TaffyPet-Setup-1.0.0.exe`
2. 双击它，一路点「下一步」
3. 装完她就在你屏幕右下角了

安装**不需要管理员权限**，也不会弹 UAC 窗口。

## 用

| 你想干什么 | 怎么做 |
| --- | --- |
| 让她说话 / 看余额 | **左键点她一下** |
| 挪个位置 | **按住左键拖**，松手就记住了，下次打开还在那 |
| 改设置 / 关掉她 | **右键点她** |

**想关掉她**：右键点她 →「退出」。

## 让她报余额（可选）

**不做这一步她也能用**，只是你点她的时候，余额那一行会显示「未设置 API Key」。

想让她报余额的话，需要一个 DeepSeek 的 API Key：

1. 右键点她 →「设置 API Key」
2. 把 `sk-` 开头的那串 Key 粘进去，点确定

Key 只存在你自己电脑上的 `%APPDATA%\TaffyPet\config.json`，不会发到任何地方去。

## 调整她

她的大小、透明度、说的话，都可以改。

设置文件在 `%APPDATA%\TaffyPet\config.json`。想打开它：按 `Win + R`，粘下面这行，回车。

```
%APPDATA%\TaffyPet
```

改之前先右键点她 →「退出」，改完再打开她。

常用的几项：

| 想改什么 | 改哪个 | 默认值 |
| --- | --- | --- |
| 她多大 | `height` | `200` |
| 透明度 | `opacity` | `1.0` |
| 音量 | `volume` | `1.0` |
| 她说什么 | `speech` | `关注塔菲喵关注塔菲谢谢喵` |
| 要不要眨眼 | `blink` | `true` |
| 要不要总在最前 | `always_on_top` | `true` |

`height` 是「逻辑像素」，会跟着你系统的缩放比例走。觉得小了就改大，比如 `300`。

**把整个 `config.json` 删掉，就全部恢复默认。**

## 卸载

Windows「设置 → 应用 → 已安装的应用」里找到「塔菲桌宠」，点卸载。

卸载**不会**删掉你的 API Key —— 万一以后想再装回来，不用重新填一遍。想彻底清干净，把 `%APPDATA%\TaffyPet` 这个文件夹也删掉。
